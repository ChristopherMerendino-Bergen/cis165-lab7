# AI Reflection

* **Tools:** I used Gemini as a thought partner to review my loop structure for `min\_max.cpp`, verify how to initialize minimum and maximum variables while avoiding the problem of hard-coding `0`, and check my test cases. And as usual, I also used Gemini to assist in formatting both .md files.
* **One decision:** I had to decide how to initialize `smallest` and `largest` while also handling the case where `-99` is the very first number entered. Instead of initializing `smallest` and `largest` to `0` at the top of `main`, I decided to use a boolean (`bool has\_data = false;`). Inside the `while` loop, when `!has\_data` is true on the first valid input, the program assigns that first number to both `smallest` and `largest` and flips `has\_data` to `true`. This allowed the program to handle all-negative, all-positive, single-value, and an empty input with one loop structure.
* **A specific check:** I tested the all-negative series `-8, -3, -12, -99` in my terminal. Before running it, I determined that `-12` is the smallest value and `-3` is the largest value (excluding `-99`). When the program output `Smallest: -12` and `Largest: -3`, it confirmed that `-99` was excluded as the sentinel and that initializing the extrema from the first input (`-8`) prevented `0` from messing with the maximum value.
* **Learning:** I can now write sentinel-controlled `while` loops that properly initialize minimum and maximum values from actual user data and handle empty inputs safely. One thing I still need to work on a bit is deciding on when to use what type of loop ('while' vs 'for') when starting to plan for a program.
